# Ника — ИИ-инфлюенсер про бизнес

`nika_reel.mp4` — пилотный ролик (26 с, 1080×1920, Reels / Shorts / TikTok).
`render_reel.py` — генератор ролика: персонаж, субтитры и музыка рисуются кодом,
поэтому любую сцену можно переписать и перерендерить за ~2 минуты.

```bash
pip install pillow numpy imageio-ffmpeg
python render_reel.py
```

## Персонаж

| | |
|---|---|
| Имя / ник | Ника, `@nika.biz.ai` |
| Роль | ИИ-бизнес-наставник: «бизнес без воды» |
| Внешность | каре с фиолетовой прядью, тёмно-синий пиджак, золотая цепочка, значок «AI» |
| Тон | дружелюбный, на «ты», коротко и по делу, одна мысль — один ролик |
| Формат | 20–60 с: хук → 3 пункта → призыв подписаться |
| Честность | открыто говорит, что она ИИ (значок «AI» в кадре), — площадки требуют маркировать ИИ-контент |

## Сценарий пилота

| Время | Заголовок | Текст за кадром |
|---|---|---|
| 0–4.6 с | 3 ошибки, которые тормозят твой бизнес | Привет, я Ника. Разберём три ошибки, которые тормозят твой бизнес. |
| 4.6–10.2 с | Работаешь В бизнесе, а не НАД ним | Первая: ты делаешь всё сам. Собственник строит систему, а не тушит пожары. |
| 10.2–15.6 с | Не считаешь юнит-экономику | Вторая: ты не знаешь, сколько стоит клиент и сколько он приносит. |
| 15.6–21 с | Боишься поднять цены | Третья: демпинг. Дешевле — не значит больше продаж. |
| 21–26.5 с | 1 разбор бизнеса за 60 секунд | Подписывайся: каждый день — один разбор бизнеса за минуту. |

## Идеи следующих роликов

2. Как поднять цены и не потерять клиентов

5. Разбор бизнеса подписчика (формат рубрики)
