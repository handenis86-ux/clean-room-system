# Seed-запросы для keyword-research — cleanroom.uz

> Назначение: «затравки» для **Google Keyword Planner** и **Яндекс.Wordstat** (Wordstat — только как инструмент исследования RU-спроса, не как канал).
> Это HEAD-термины — инструменты сами раскроют длинный хвост и покажут related. Не нужно вбивать все вариации руками.

## Как пользоваться

**Google Keyword Planner** (нужен аккаунт Google Ads):
1. Tools → Keyword Planner → «Discover new keywords».
2. Гео: **Uzbekistan**. Язык: **Russian** (прогнать отдельно **Uzbek**). Сеть: Google.
3. Вставлять по 5–10 seed-терминов из кластера → смотреть «Keyword ideas» + объём (диапазоны) → экспорт в CSV.
4. Для ниши объёмы будут низкие/0 — берите related-идеи и формулировки, а не абсолютные цифры.

**Яндекс.Wordstat** (wordstat.yandex.ru):
1. Регион → выбрать **Узбекистан**.
2. Вбивать по одному seed → смотреть «Что искали со словом» + частоту.
3. Полезны «右»-колонка (похожие запросы) и операторы: `"кавычки"` (точная фраза), `!слово` (словоформа).

**Что делать с результатами:** это словарь для (а) таргета Google Ads, (б) текстов/названий товаров, (в) скриптов продаж — НЕ для погони за generic-SEO (в UZ малорентабельно).
