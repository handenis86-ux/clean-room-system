## 0. Guardrails — защита от санкций (читать перед каждым шагом)

Поисковики (Google + Яндекс) штрафуют за манипуляции. На каждой правке держим:

1. **Без keyword-stuffing.** Один primary-запрос + естественные синонимы на страницу. Не «перчатки перчатки нитриловые перчатки cleanroom перчатки купить».
2. **Уникальный контент.** Никаких spun/дублированных текстов между категориями. Каждый intro/section — написан под конкретную категорию (файлы `category-seo/*` уже раздельные — держим так).
3. **Против каннибализации.** Один запрос = одна каноническая страница. Коммерческий интент («купить обувь для чистых помещений») → страница каталога; информационный («валидация дезинфекции») → resources/blog. Проверяем, что каталог и блог не дерутся за один и тот же коммерческий запрос.
4. **Title без пере-оптимизации.** ≤ 60 символов, естественный, 1 primary-запрос. **Убрать одинаковый на все 30 категорий шаблон-хвост** «в Узбекистане — купить для GMP / ISO 14644 в Ташкенте» → делать интент-специфичные заголовки для приоритетных категорий.
5. **hreflang для /uz/.** Для garments / disinfectants / perchatki есть узб-версии — hreflang reciprocal и корректный, чтобы ru/uz не считались дублем. Узб-контент — реальный перевод, не копия ru.
6. **Внутренние ссылки — естественные анкоры.** Варьируем текст ссылок, без exact-match спама одним анкором.
7. **Никаких дорвеев.** Геозапросы (Ташкент/UZ) закрываем через hreflang + одну гео-страницу, не плодим тонкие «обувь Ташкент / обувь Самарканд / …».
8. **Постепенность + замер.** Меняем приоритетную пачку → ждём 2–3 недели (переобход + лаг GSC) → замеряем `/week` + точечные запросы → только потом следующая. Не бластим весь сайт разом (нельзя атрибутировать + выглядит манипулятивно).
9. **E-E-A-T.** Экспертный контент подкрепляем авторством/ревью IBC Nanotex (Вячеслав/Булат) — усиливает доверие, снижает риск «thin content».

## 🔑 ГЛАВНЫЙ ВЫВОД (v2 — после аудита кода и UZ-фильтрации спроса)

**Корректировка (важно):** первичная гипотеза «у части категорий нет SEO-контента» оказалась ошибкой измерения (grep пропускал ключи без кавычек). Факт после точного аудита:

> **ВСЕ 30 категорий уже имеют уникальный rich-контент (intro + 3–5 разделов + FAQ + внутренние ссылки + JSON-LD).** On-page-контент — уже сделан по всему каталогу. Создавать контент не нужно.

Второй факт, из UZ-фильтрации спроса (салфетки, дезинфектанты, обувь, мебель — одна картина):

> **Generic-запросы («дезинфицирующие средства», «обувь для чистых помещений») = в основном иностранный (RU) трафик + позиции 25–46 (упираемся в авторитет домена). По бренд/товарным запросам (contec prochlor, tego 2000, sbt102pc, «дезинфектант») мы УЖЕ стоим pos 1–8.**

**Вывод: узкое место — НЕ контент (он есть) и НЕ generic-запросы (их узбекский рынок не ищет). Узкие места — (1) авторитет домена и (2) title/CTR-гигиена + товарные заголовки.** Реалистичная задача органики: дёшево ЗАБИРАТЬ концентрированные бренд/товарные/локальные/узбекские запросы (где мы уже pos 1–8) и наращивать авторитет. Совпадает с диагнозом продаж: заводы находят CRS не через поиск.

## Приоритеты (по убыванию ROI)

### 🥇 P1 — Дезинфектанты (`disinfectants-and-detergents`)
**Почему:** макс. спрос (landing 202 + head-термины: «дезсредства в фармпроизводстве» 36/pos 28.9, «дезинфицирующие средства для чистых помещений» 21/pos 34, «спец. чистящие» 17/pos 36, «contec prochlor» 7/pos 7.6) при **худших позициях (17–38)**. Уже есть seoH1 + rich-контент — значит проблема не в отсутствии контента, а в таргетинге/качестве/структуре.

Задачи:
- [ ] **Аудит** текущего `category-seo/disinfectants.ts` + meta-title: под какие запросы реально заточен, нет ли размытия.
- [ ] **Title** сделать интент-точным под «дезинфицирующие средства для чистых помещений / фармпроизводства» (не шаблон-хвост), ≤ 60 симв.
- [ ] **Контент** усилить под реальные запросы: ротация бактерицид/спорицид (§11), «дезсредства для фармпроизводства». Естественно, без стаффинга.
- [ ] **Товарные страницы** топ-спроса: contec prochlor (pos 7.6), tego 2000, contec ipa, sbt102pc — выверить title/H1 = название бренда+тип (то, как ищут).
- [ ] **Кросс-линк** с resources/disinfection-validation-protocol (инфо→коммерц, разный интент — каннибализации нет). Калькулятор уже подшит.
- [ ] Замер через 2–3 недели: цель pos 17 → ≤ 10.

### 🥈 P2 — Обувь для чистых помещений (`cleanroom-shoes`)
**Почему:** концентрированный спрос с коммерч. интентом («обувь для чистых помещений **купить**» 4/pos 24.5; «сабо…» 16/pos 22; «обувь для чистых/стерильных помещений» 15+12/pos 13–23), низкая конкуренция, но мы на **стр. 2–3**. Есть rich-контент, но **нет seoH1** (fallback на длинный title).

Задачи:
- [ ] **Добавить `seoH1`** в products.ts: напр. «Обувь и сабо для чистых помещений (ESD, автоклавируемая)» — под реальные запросы.
- [ ] **Title** под «обувь / сабо для чистых и стерильных помещений» + «купить».
- [ ] **Аудит `category-seo/ppe-accessories.ts` (cleanroom-shoes)** — усилить под «сабо», «стерильные», материалы/автоклав.
- [ ] Замер: pos 16 → ≤ 8.

### 🥉 P3 — Одежда одноразовая (`garments`)
**Почему:** хороший спрос («одноразовая одежда» 17/pos 18; узб. «bir martalik kiyim» 4) + **лучшая on-site вовлечённость (4:42, 39 просм)** + уже pos 8. Есть seoH1, **но нет rich-контента вообще** — прямой безопасный апсайд.

Задачи:
- [ ] **Написать rich SEO-контент** (`category-seo/consumables.ts` → ключ `garments`): intro + разделы (типы комбинезонов, зоны A/B/C/D, стерильные vs нестерильные, материалы SMS/микропористые) + FAQ + внутренние ссылки. Уникально, экспертно (ревью IBC).
- [ ] **Title/seoH1** дожать «одноразовая одежда / комбинезоны для чистых помещений».
- [ ] **/uz/catalog/garments** — проверить, что реально таргетит «bir martalik kiyim», hreflang корректен.
- [ ] Замер: «одноразовая одежда» pos 18 → топ-10; удержать landing pos 8.

### P4 — Вторичные (после P1–P3, по одной)
- **Перчатки** (`perchatki-zashchitnye`): есть всё, pos 10, термин «перчатки защитные» pos 21 — точечно дожать title/контент. Средний приоритет.
- **Очки** (`goggles`): спрос ~45 показов, но **нет ни seoH1, ни контента**, pos 18–32, и **интент размыт** (строительные/защитные очки ≠ cleanroom). Добавить seoH1 + контент строго под «очки для чистых помещений / автоклавируемые», НЕ гнаться за общими «очки защитные» (чужой интент, риск нерелевантного трафика). Осторожно.
- **Уборочный инвентарь** (`cleaning-equipment`, `cleaning-trolleys-systems`): «телескопические ручки для инвентаря» 10/pos 25 — есть контент, дожать title.

### 🛡️ Defend — не трогать, только мониторить
- **Индикаторы** (`indicators`): pos 7, CTR 5%, уже конвертит. Спрос — SKU/бренд (Terragene/Bionova). Риск сломать > апсайд. Оставляем; следим, чтобы не просело.
- **Липкие коврики** (`cleanroom-sticky-mats`): pos 3.9, мало спроса — ок.

### ⛔ Не SEO — другой канал
- **Мебель TINMAN** (стулья, урны, скамьи и пр.): в поиске ~0, но **on-site глубоко** (урны 16:21, стулья 9:42) → покупатели идут через бренд/прямой/рефералы. Вкладывать в **бренд-страницу TINMAN + sales-follow-up**, не в органику.
- **Салфетки безворсовые** (`cleanroom-wipes`): спрос в UZ ~0 (диффузный хвост), pos 9. SEO не даст объёма — оставляем как есть.

## Порядок движения
1. **Phase 0** — проверки санкций + baseline (сделано частично).
2. **P1 дезинфектанты** — аудит → title → контент → товары → замер (2–3 нед).
3. **P2 обувь** — seoH1 → title → контент → замер.
4. **P3 одежда** — контент → title → /uz → замер.
5. **P4** — по одной категории.
6. Каждые 1–2 недели — контроль через `/week` + точечные запросы; при просадке позиций откат.

- Ноль ручных санкций в GSC/Яндекс.
- Отсутствие каннибализации (один запрос — одна растущая страница).
